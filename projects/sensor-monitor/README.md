# Raspberry Pi Sensor Projects

A collection of Raspberry Pi projects developed using Python for
sensor integration, real-time data collection, and monitoring.

## Overview

This repository contains practical Raspberry Pi projects focused on
hardware-software integration and real-time sensor data processing.

The projects demonstrate how Python can be used to communicate with
sensors through Raspberry Pi GPIO and process sensor readings.

## Projects

### 1. Sensor Monitor

A Python-based Raspberry Pi application that reads digital sensor input
through GPIO and continuously displays the sensor status.

**Technologies:**
- Python
- Raspberry Pi
- GPIO
- Digital Sensors
